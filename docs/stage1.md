# 第一阶段环境与指标修复

## 已验证行为

- 储能充放电效率与环境时间步一致。SOC 0.11、下限 0.10 时允许放电 19 kW，下一状态为 0.10。
- 无安全层时仍根据真实下一状态统计越限。修正前风险与执行后越限分别记录。
- 并网模型下，主网实际交换功率由真实净负荷决定，显式记录计划偏差。越过主网容量时记录违规，不假装通过裁剪消除了能量缺口。
- 弃电是显式动作，受可再生出力限制；弃电增加净购电，潮流注入按比例扣除弃电。
- SOC 不再被静默截到 0–1。不可行轨迹仅供仿真诊断，不能解释为可部署运行。
- 每个时刻的观测有缓存，重复读取不再次发包或融合；通信费用只结算增量。
- 终止步仍保存实际 SOC；reset 清除状态，避免跨回合继承。
- 消融按场景、方法和 variant 分组。单列记录数和独立种子数。
- 传统与神经方法采用相同测试场景种子偏移。

## 测试

`python validation/test_stage1.py`：11 项通过。覆盖边界、非单位效率、无安全层越限、主网结算和容量、观测幂等、增量计费、弃电与潮流平衡、终止和重置、消融分组、非有限动作。

当前运行环境未安装 PyTorch、PuLP 和 pytest，因此没有运行完整 RL、MILP 或原项目全量测试。核心验证使用标准库 unittest 和 NumPy。

## 尚未解决

- 实际上传调度、端到端时延、计算完成门控与通信队列机制仍需重写。
- DT 尚未接入训练型残差网络及完整历史执行动作；无误差界安全保证。
- 旧 MAPPO/IAC/完整方法类仍存在覆盖与同构问题，不作为可信对比。
- MILP 弃电符号、效率、目标函数、预测特权与求解回退仍需修复。
- 奖励仍含人工 penalty，不能直接称为实际货币成本；暂无真实碳排或 Pareto 学习。
- 电网仍为简化后端，不能称为标准 IEEE 33-bus AC 验证。
- 当前安全层只处理部分约束；EV 离站、DR 能量转移和鲁棒安全过滤尚未实现。
- 时间指标与部分旧评估器仍需统一；旧训练统计不能作为论文结果。
