# DT 验证、偏好条件 MAPPO 与多目标实验协议

本次新增 `vpp_research`，原 `vpp_mappo` 官方普通 MAPPO、固定权重对照和能源 MILP/MPC 均保留。研究实现支持 CPU；没有将固定权重扫描改名为 Pareto-MAPPO。

## 0. DT 与固定观察

固定观察版本 `c3-65-state-interval-carbon-v1`：原有 54 维公开观察，追加 9 个状态估计区间半宽、1 个分布外提示、1 个通过遥测到达的碳强度。集中式 critic 也只能读取这些公开观察。

残差模型是正则岭回归，不是深度残差网络。它以已完成传输/计算的缓存、AoI、队列和物理 DT 预测为输入，修正 SOC、EV 聚合剩余需求、DR 状态、负荷、价格、光伏、风电共 9 个归一化量。模型不读取在线真实标签；真值只用于离线拟合、校准及日志核算。残差输出为状态估计，不是凭空获得未到站车辆的真实车表。

训练/校准/测试按场景分离。训练集拟合归一化和残差系数；独立校准集按每个场景所有时刻、所有目标的最大标准化误差形成一个分数，取 `ceil((n+1)*(1-alpha))` 阶次统计量，当前 alpha=0.1。校准场景不足时拒绝有限区间，不能把分位数静默截断。协议参考 [Angelopoulos 与 Bates 的共形预测介绍](https://arxiv.org/abs/2107.07511)。

名义覆盖依赖适当的交换性假设。改变控制策略、出现通信故障、跨月真实数据或分布外运行时只报告实测覆盖，不能把离线校准转换成自动成立的在线安全保证。相关限制参见 [非交换数据下的 split conformal 研究](https://arxiv.org/abs/2203.15885)。OOD 提示是归一化特征超过训练尺度的启发式，不是经过验证的分布外检测器。

DT 验证分两层：

1. 相同物理候选指令和场景下，比较保持观测、纯物理 DT、残差 DT 的估计误差和区间覆盖。
2. 冻结模型，使用相同 MPC 和独立测试场景比较成本、安全干预、估计误差及覆盖。不能用估计误差下降代替控制收益证据。

## 冻结的 C3 三目标

统一最大化向量：

- 经济：`-(电费 + ESS 退化 + DR 补偿 + 弃电费 + 通信/计算能耗费 + 日末 SOC 短缺罚项) / 100`。
- 碳：`-(主网进口运行排放 + 通信计算能耗对应排放) / 100`，单位 kg；出口不抵扣，储能放电不重复计入。
- 备用：`对称可交付备用 kW × 调度步长 h / 100`。依据执行后状态及当前工况持久性预测，保留已知 EV/DR 约束，求下一步上/下调包络；日末记零。它是可用备用指标，不是实际履约电量，不表示整日同时可交付所有时刻备用。

版本 `c3-cost-carbon-symmetric-reserve-v1`，尺度固定 `(100,100,100)`，不按测试结果重缩放。基础设施能耗单独计费、不注入 IEEE33 馈线，并暂用相同地区时刻碳因子。AC 成本/违规单列；备用仍是线性模型结果。实际运行指标属于奖励/评价核算，不额外加入策略或 critic 的真值输入。

安全罚项对每个目标施加相同数值，因此权重和为 1 时不会因偏好而规避处罚。用于 HV/IGD 的经济—碳—备用向量仍保留原定义，违规点不能混入可行前沿。备用求解失效明确标记，相关点不进入有效前沿。

## 1. 偏好条件 MAPPO

- actor 输入公开观察与三维偏好，输出连续高斯动作；偏好在一个完整回合内固定。
- 集中式 critic 输入联合公开观察与偏好，输出三维价值。
- 先计算向量 TD/GAE/回报，再按偏好标量化 actor 优势；不分别标准化目标优势以免隐式改变偏好。
- PPO 使用每个智能体的动作概率比和截断，critic 回归三个目标，记录并校验有限损失。
- 训练偏好混合顶点与 Dirichlet 内部采样。测试使用预先固定的未见偏好，并核查是否在训练中出现。
- 保存/重载 actor、vector critic、观察/目标版本、资源参数、DT 模型和训练偏好。

这是单个偏好条件模型的完整主训练路径；尚不能凭短程测试宣称覆盖真实 Pareto 前沿。线性标量化偏好训练也不保证覆盖非凸前沿的所有非支撑解。

普通和固定权重方法调用固定版本官方 MAPPO；新 Pareto 模块是独立实现，并不声称是上游官方 Pareto 算法。

## 2. 预算、评价及消融

默认验证使用 5 个训练种子，每个方法族 12 回合 × 8 步 = 96 次环境交互。固定权重族包含 3 个模型，每个 4 回合，合计预算仍为 96 步；不是给每个模型额外完整预算。相同环境交互预算不等于相同参数量、agent 决策次数或实际训练耗时。

固定资源组比较普通、固定权重族、偏好条件、去残差、去协调器。联合组另比较 18 智能体普通 MAPPO 和偏好条件 MAPPO，能源、上传/带宽和 CPU 都参与决策。两组分别报告，不能把改变动作空间的结果当成纯算法差异。

最终迭代模型按预定预算固定，不使用测试集挑选 checkpoint。HV 参考点预注册为 `(-50,-50,0)`。IGD 参考集只来自验证场景上的经验非支配集，不是真实已知 Pareto 前沿。测试点按同一偏好跨场景平均，若其中任一场景失败或违规，则不将该点列入可行前沿；同时报告失败数和无定义 IGD，避免只展示成功样本。五种子均值、标准差与 t 区间可复现，但短预算和小样本不能证明收敛。

普通 MAPPO 作为单个目标点，固定权重族作为多个点，偏好策略在未见偏好上生成多个点。经济 MPC 单独作为参考，不重复成多个训练种子，也不假装是多目标优化器。

## 区间保护及安全压力

新增保护器对已校准的负荷/光伏/风电盒顶点，检查单步 LinDistFlow、电网进出口、SOC 和部分 DR 容量约束，并以线性规划求归一化 L1 最近动作。

重要边界：它不是完整逐车/全时域鲁棒优化，也不是 AC 鲁棒证明。区间可能不含真值。区间矛盾或求解不可行时明确记失败，继续交给原本地实时安全层；现场安全层改写动作后重新检查证书是否仍成立。若现场也不可行，整个回合标记失败，不伪造“零违规”。目前尚未实现紧急服务降级和证明递归可行的后备控制。

压力测试包含 30% 丢包、CPU 中断、带宽下降、风电突变、负荷冲击，并在同一训练策略下比较开启/关闭区间保护。这是部署干预实验，不能冒充重新训练的安全消融。仿真仍未把推理和安全求解耗时纳入模拟 CPU，也未包含真实下行链路。

## 真实数据范围

下载并校验 OPSD 固定版本原始数据；按 UTC 日期和时间顺序分割，用训练段峰值缩放到 IEEE33。国家级曲线不是原生馈线实测。

真实曲线 DT 实验采用 2019 年 1 月训练、2 月校准、3 月测试，从各段选择预先固定数量的完整日期。缺少真实 EV 会话时明确关闭 EV；没有真实碳强度时只做估计与经济控制验证，不计算伪造的三目标真实前沿。

完整真实实验仍需：接入时已申报的 EV 需求/期限、同地区同时段碳强度、通信/计算硬件参数。ACN-Data 可提供充电会话，其字段包含 userInputs 的修改时间、请求电量和申报离站时间；不能用事后实际离站和已交付电量替代在线申报。[ACN 官方说明](https://ev.caltech.edu/dataset)。美国 ACN 与德国 OPSD 直接组合只能称为跨来源合成场景，不能声称同一物理 VPP 实测。

## 直接运行

按仓库说明安装原有 MAPPO/IEEE33 依赖后：

```bash
python -m vpp_research dt --output runs/dt
python -m vpp_research suite --dt-folder runs/dt --output runs/fixed --episodes 12
python -m vpp_research suite --joint --dt-folder runs/dt --output runs/joint --episodes 12
python -m vpp_research.audit_ac --suite-folder runs/joint
python -m vpp_mappo.download_opsd --output data/raw/opsd.csv
python -m vpp_research real-data --raw data/raw/opsd.csv --output runs/real
python -m unittest discover -s validation -p 'test_stage*.py'
```

结果及模型分别写入对应输出目录；原始训练标签仅供离线审计，不进入在线输入。默认命令是可复现短程验证，不是论文最终训练预算。模型训练域、观察版本、目标尺度和数据来源必须一并保存，跨域复用需重新验证和校准。

## 执行前 AC 校核

`ResearchEnv(ac_safe=True)` 可启用有限次线性边界收紧与真实 AC 校核，合格动作才推进物理状态。无可执行动作则报错并锁定回合，必须 reset；没有已验证紧急后备控制。独立冻结策略审计使用上述 audit_ac 命令，保留原不带 AC 修正的压力结果。求解耗时被记录但尚未纳入仿真 CPU 队列；校核通过只说明该步对应 AC 模型满足检查项。
