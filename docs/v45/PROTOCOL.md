# v4.5 问题与证据边界

## 公共终端库存服务

储能功率正号表示放电，效率为η，容量为E，时间步为Δt：

s(t+1)=s(t)+[η max(−p(t),0)−max(p(t),0)/η]Δt/E。

公共终端区间为[s*−ε,s*+ε]与设备SOC范围的交集。主配置s*=0.55、ε=0.01、E=500kWh，因此区间[0.54,0.56]仍允许最多5kWh相对初始库存差；需要严格能源中性时应预先把ε设为0并重训全部方法，不得事后只修改某个策略。

给定末端剩余n步，仅考虑储能设备能力的必要可达区间为：

L(n)=max(s_min,s*−ε−n P_max η Δt/E)，
U(n)=min(s_max,s*+ε+n P_max Δt/(ηE))。

安全层对下一状态施加[L(n),U(n)]，共享MILP另外显式约束全剩余时域末端库存。这些条件不证明未来网络约束可行，也不假设未来风光/负荷已知。Oracle读取真实未来，单独标为非因果参考。

## 安全结果的四个层次

1. 候选动作质量：策略原始候选、下行实际到达候选及修正幅度。
2. 事前区间证书：给定校准区间的单步线性约束是否存在共同动作，以及执行后证书是否保留。
3. 现场执行检查：即时设备和AC潮流约束。有限AC检查不等于连续不确定集的AC鲁棒保证。
4. 服务履约：EV需求、DR回补、公共终端库存。紧急时可以服务降级，但不得进入“全部可行”的Pareto集合。

无硬安全动作时终止该案例并保留失败；不把未执行时段补成零成本或零违规。故障场景中的成功拒绝执行是后备逻辑证据，不是系统持续供电能力证据。

## 学习与评价

评价向量固定为[−AC成本/100,−运行碳kg/100,经有限激活核验的对称备用kWh/100]。公共库存模式不再计旧终端罚项，不能与旧协议直接比较提升率。训练外生中心化不改变原始评价、模型选择或参考点。

条件策略与固定端点的32回合诊断中，各单策略预算相同，但端点家族总预算为条件策略的三倍。完整七方法入口另外按家族分配总训练预算；选择交互和额外critic计算必须单列。OLS提前停止则按实际预算标注，不补造训练调用。

偏好梯度余弦来自同一更新批次上实际采样的标量化损失，不是多个目标梯度的任意融合。负余弦表明局部方向冲突，未证明该冲突有害；未采到纯偏好的批次用pure_steps=0标识，不将占位余弦0作为证据。

## 通信与计算的作用条件

当前能源控制周期为1小时，C3队列在周期内模拟传输与处理。若不同分配都让同一批报文在下一控制边界前完成，下一步估计和控制可能完全一致，只有内部完成时刻不同。协调分配发生变化不能单独证明节约成本。

机制网格包含2000/10000bit/s和2×10^6/10^7cycle/s，并保留全部四种资源控制模式。使用冻结策略做反事实只能识别部署敏感性；要证明联合训练价值，必须在相同家族预算下分别重训各模式。计时来自当前服务器，存在并发干扰；模型能耗不冒充硬件实测。

## 数据与外部检验

GB OPSD能源及NESO碳是国家曲线驱动IEEE配网仿真，不是IEEE33实站数据。SCE响应只作显式跨地区参数敏感性。ORNL发现样本只有26条，小时级因果审核通过1条，不构成完整EV数据集；没有真实提前离站事件的样本不能证明提前离站鲁棒性。跨日会话目前被明确排除，跨日连续调度仍未实现。

IEEE69复用IEEE33的DT区间只能作为转移验收。需要在新网络上独立拟合/校准并使用外部测试才能主张跨网泛化和覆盖保证。四月至六月确认性测试集仍封存，本轮只作开发诊断。
