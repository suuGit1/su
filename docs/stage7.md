# 第七阶段：观察等价 MPC 与任务/风险协调器

本阶段补上路线 A 的可比较控制器和规则协调器。基础 DT 仍是物理预测/保持观测；残差学习、概率不确定性及完整 Pareto-MAPPO 尚未实现。

## 同等信息的含义

新增 `ObservedMPC` 只接收与策略相同的 54 维公开观察以及静态资源规格。对象没有环境、DT 缓存或未来场景引用。其负荷、价格、风光、SOC、EV 需求与 DR 状态均来自该观察。预测采用当前估计持久性延伸至日末；经济窗口为 lookahead，日末可行性尾部沿用共享 MILP。

当前观察只有 EV 总需求、数量和最近期限。因此 MPC 将总需求映射为一个最近期限任务，以站级功率为上限。期限聚合偏保守，单车功率信息缺失又使功率限制放宽，整体不能声称为严格保守模型。它是**观察等价的聚合 MPC**，不是读取完整逐车记录的 MPC。不得私下从 DT 取车表强化这个对照。

MAPPO 与 MPC 使用相同的本地安全执行器：两者都提交六维候选动作，均经 `step_candidate` 和现场 MILP 校正。MPC 不绕过安全层，不将其聚合分车计划冒充物理车队计划。

估计不可行时，MPC 明确记录失败、原因、耗时，并提交零候选动作，由共同的本地安全层处理。零候选不是经过证明的安全后备策略。如果本地安全层也无可行解，现有行为仍为明确报错，不能保证任务完成。

## 两类核查

1. **逐状态影子 MPC**：每个 MAPPO 决策时刻，将其完全相同的观察交给 MPC，只记录建议，不执行。轨迹保存 `controller_observation_json`、影子动作和求解状态。
2. **独立闭环配对**：相同场景种子、物理参数、DT 模式、通信计算规则和安全层，分别执行 MAPPO 与 MPC。动作不同会导致后续状态、包大小、队列与缓存不同；同等信息权限不意味着后续观察数值完全相同。

本次能源控制比较要求 `cyber_mode=fixed`，并且协调器配置相同。固定的含义是使用相同规则，不保证依赖状态的风险调度分配每步相同。联合通信计算策略不能自动套用该比较并宣称公平，须另设计全系统比较组。

推理、MPC 和安全求解有程序耗时记录，但尚未占用事件模拟器的 CPU；所以当前对照不比较真实端到端时效。丢包使用相同随机种子和模型，实际完成顺序可因动作改变，不能宣称逐数据包经历完全相同。

## 规则式协调器

`TaskRiskCoordinator` 同样只使用公开观察。配置随检查点保存，并有独立版本校验。

- `off`：保留原行为。
- `monitor`：生成任务和风险日志，不改变资源分配。
- `schedule`：按观察中的 AoI、EV 服务余量、DR 日末补回压力、SOC 边界距离产生优先级，将一部分带宽和 CPU 保留给这些任务；剩余部分遵从原分配。

配置：`coordinator_aoi_limit_steps`、`coordinator_deadline_margin_steps`、`coordinator_soc_margin`、`coordinator_reserved_fraction`。最后一项是资源配额比例，不是概率风险预算。

任务记录包括各通道 DT 刷新、聚合 EV 服务和 DR 补回的剩余工作与期限。DT 刷新任务的优先级会实际改变队列服务；能源任务期限同时由 MPC 和本地安全层约束。EV 服务余量使用站级能力，属于乐观估计，不是逐车服务保证。

每个通道保留基础权重，避免仅按风险优先而永久饿死其它资源。风险分数为阈值启发式，不是违约概率或校准置信度。本阶段没有 LLM、动态偏好生成或任务市场。

## 运行

```bash
python -m vpp_mappo train --config configs/c3_coordinated_smoke.json --output runs/c3_coordinated
python -m vpp_mappo.compare --checkpoint runs/c3_coordinated/latest.pt --output runs/c3_comparison --episodes 2 --lookahead 2
```

也可直接使用 `python -m vpp_mappo.cyber_compare`。真实评估支持 `--csv` 与 `--ev-sessions`，并复用已有训练/测试场景隔离检查。

比较目录有 learned 和 mpc 的轨迹、回合指标、paired.csv 与 comparison.json。协调器任务和风险原因在 `coordinator_json`；求解失败数、安全干预、EV 欠充、DR 欠供及 AC 违规均保留。原 `cyber_mode=off` 的能源 MILP/MPC 不受影响。

## 验证结果和研究进度

62 项回归测试通过，含信息隔离、估计不可行、风险分配预算、只监测不改动作、非法分配不推进状态、统一安全执行器及联合模式误标拒绝。普通 MAPPO 完成两回合训练和两个独立合成场景评估。

本次 MPC 闭环和影子求解均无失败，MAPPO/MPC 已检查的线性和 AC 违规均为零，EV 离站欠充与日末 DR 欠供为零。MPC 的成本低于短程 MAPPO；这是合理的基线结果，不是论文收敛证据。

| 层次 | 已实现 | 仍需补齐 |
|---|---|---|
| 物理环境 | IEEE33、ESS/会话 EV/DR/弃电、统一能源约束、AC 审计 | 真实 EV 校准、更广压力场景、AC 安全回退 |
| 通信计算 | 上行/计算队列、带宽/CPU 决策、AoI 与事件日志 | 推理/安全任务计时、下行、真实硬件参数 |

## 完整 Pareto-MAPPO 何时接入

顺序明确为：**本批公平对照 → 下一批 DT 残差与不确定性 → 再下一批 Pareto-MAPPO 主体**，不等全部真实数据和扩展电网到齐才开始算法。

DT 批次必须先固定观察版本、数据分割、目标归一化和 C3 成本/碳/备用定义。残差训练仅使用训练场景，校准集与测试集独立；在线特征不包含未来实际测量。先比较保持观测、纯物理和残差融合的预测误差与区间覆盖率，再验证下游控制影响。

随后完整 Pareto-MAPPO 至少包括：偏好条件 actor、三维 critic、向量回报/GAE、偏好采样与显式标量化规则、验证集选策略、未见偏好测试、固定参考点 HV/IGD、统一训练预算和多种子统计。普通 MAPPO、固定权重 MAPPO 与 MPC 持续保留。未完成这些内容前，不把固定权重扫描称为完整 Pareto-MAPPO。

当前最重要的是获得**可检验的 DT 误差与任务价值**，并冻结 C3 三目标口径；否则提前训练 Pareto 只会对不稳定的目标和信息接口反复返工。完整鲁棒安全与大规模实验是后续验收项，不因标题含 Safe 而视作已经完成。
