# 周期内服务分配复验

保留已有原版与映射版，新增 ServiceCoordinator。120例：两种服务优先级各48例，价值代理版另有24例任务切换。日期、种子、MPC、DT及三目标核算保持原冻结矩阵，全部使用三月开发集。

## 服务上界

公开本地调度信息新增每通道队列长度、剩余bit/cycle与任务数；不读取待传感器载荷、物理真值或未来。这个额外接口同时向所有对照开放；旧基线不使用它，不能声称观察张量完全不变。

对选择集合S，A_i为剩余传输量加本步新报文上界，D_i为计算积压加待传报文的更新量。当

sum(A_i)/B + sum(D_i)/C <= T

时，以两阶段传输/计算时间比例构造资源下界，将剩余额度按优先级分配。实际系统可并行流水，因此这是保守的充分条件。C已经扣除控制命令计算预算；T取3600秒控制周期，不是900秒遥测服务期限。载荷上界为8192 bit，逐步用事后事件审计；丢包、溢出不受确定性完成上界保证。队列满时不承诺新样本，仍可处理积压；单任务也无法按时完成时显式撤销完成承诺并继续处理一个高优先级任务。未获得分配的任务不会伪造为完成。

## 两种优先级

- service_risk：保留映射版风险/任务权重，只增加服务准入与资源下界。
- service_value：采用公开DT区间在一步功率平衡中的局部误差传播代理，分别估计经济、碳、备用的不确定性影响，再结合AoI分配。平衡任务等权，其他任务使用单目标代理。能源MPC目标不变。

后者不是严格的最优信息价值；尤其在单期线性购电模型下，碳与备用代理可能成比例，因此无法凭名称保证不同任务带来不同策略。这种不可辨识性须在结果中报告，不能视为成功的多目标切换。

## 判据

审计预算、掩码、样本完成上界、载荷越界、900秒迟到和网络丢弃。对每个瓶颈保留成本、碳、有效备用及逐日差值。报告步骤和日期、网络种子，不能把重复种子当独立日期。支持服务完成不自动支持经济效益；支持经济收益不自动支持任务方向性。
