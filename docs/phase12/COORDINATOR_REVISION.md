# 协调器修订复验（开发集）

本轮保持 v1 全部实现与案例不变，新增可选 MaskedRiskCoordinator 和独立运行入口。默认训练环境仍使用 v1；候选版尚未获得默认替换资格。

## 修改与不变项

- mask_only：有效通道为0、2、4、5。分配前屏蔽停用EV与削减通道，重新归一化基础权重与风险优先级；风险比例依据有效通道计算。有效掩码由设备配置明确提供，不根据某时刻EV需求为零推断永久停用。
- mapped：在mask_only之上，依据DT目标与遥测载荷的真实归属聚合区间风险。通道2含移峰积压、移峰累计、负荷、电价；通道3对应削减累计。归一化尺度0.05及风险上限5保持原值，多目标通道取最大值。
- 保留原任务权重、能源MPC、DT权重、场景、带宽/CPU总预算、网络种子及全部安全层。因而任务权重可能仍无效，复验不保证方向正确。
- 新记录逐通道AoI、有效通道AoI、候选与执行动作、命令时延。AoI记录为决策前值，不能和旧汇总的其他采样时刻混用。

## 固定矩阵与判断

四资源条件×8日期×两修订，组合条件3网络种子，其余1种子，共96例。映射版额外测试经济、碳、备用任务各8日，共24例；平衡任务使用该版本C3组合条件seed431的8例。合计120例。沿用第一轮预定日期与既有三月数据，未读取封存确认集。

对照包括原版joint_risk、active_equal、uniform，均使用相同日期与种子。先按日期聚合种子，再报告均值及逐日差异；共同种子不等于逐报文损失相同，因为上传掩码可能改变随机数消费顺序。

机械验收：停用通道分配为零、总预算不超额、完整轨迹有24步、无静默失败、运行配置/源代码哈希固定。效果验收：完整报告各瓶颈成本/碳/备用和有效性；经济任务比较成本、碳任务比较碳、备用任务比较有效备用。某一瓶颈收益不得替代其他瓶颈退化。开发集结果不能作为显著性或新数据泛化声明。
