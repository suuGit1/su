## 已定位问题与后续修订边界

1. 协调器对全部通道保留权重，停用EV/DR时仍可能分配资源；应明确有效遥测掩码，同时保留承载负荷/价格/碳的通道2。
2. interval_width使用[0,1,2,4,7,8]的映射未直接纳入负荷目标5，应按“状态目标—遥测通道”映射聚合，而非每通道取一个索引。该问题是代码审计线索，尚未通过干预实验确证全部因果效应。
3. 现有任务权重是启发式，未反映不同遥测对控制目标的边际影响；不能通过给任务改名或增加权重就保证定向改善。应单独冻结修订版并与原版及均分强基线配对。
4. 全6通道AoI包含停用通道，不能作为有效信息新鲜度指标。下一轮应记录逐通道AoI、执行/丢弃时间戳及实际动作，保留本轮原始记录。
5. 所有修订继续使用开发集，确认集保持封存。修订版需预先定义瓶颈区间、负面结果处理和按日期配对分析，不能只保留有利瓶颈。

本轮不包含真实EV/DR服务验证、硬件通信/推理能耗实测或Pareto学习优越性实验。以上属于后续证据，不应以当前机制结果替代。第一阶段协议已落实，第二阶段实验执行已完成，预期机制的正向结论仅部分成立。
