# 第十二阶段：训练与模型选择的统一交互预算

新增 `vpp_research.fair_budget`，普通官方MAPPO、固定权重MAPPO、偏好条件Pareto和OLS使用同一v3 PCC口径。总开发预算定义为训练环境交互加模型选择/自适应验证交互。独立测试另外计账，各方法运行相同测试偏好与场景数量。

## 已实际运行

配置 `configs/fair_budget_smoke.json`，时域2步，种子31，未加载DT残差模型。该设置专用于验证预算及数据隔离，不用于论文性能比较。

|方法|训练交互|选择交互|两者合计|独立测试交互|子策略数|
|---|---:|---:|---:|---:|---:|
|普通MAPPO|20|4|24|12|1|
|固定权重MAPPO|12|12|24|12|3|
|Pareto-MAPPO|8|16|24|12|1|
|OLS-MAPPO|8|16|24|12|4|

四个方法全部完成，总计9个模型；预算匹配全部通过。101项回归测试通过（38.909秒）。OLS的4个子策略和各自验证回合均计入预算；没有把它们当成免费计算。固定权重与OLS按验证回报选择成员，测试回报不参与选择。测试请求偏好与被选子策略的训练/输入偏好分别记录。

普通MAPPO把较少的选择开销留给更多训练。这是同总交互量比较，不是同梯度更新量或同CPU时间比较。MILP/潮流的计算成本也不因环境步数相等而相等，工程计时仍需单独分析。

## 失败与恢复

- 分配时先扣除所有选择回合，再均分子策略训练回合。不可整分或训练配额不足会在开始训练前拒绝。
- OLS角点提前耗尽、验证不可行或执行失败时，保留实际训练与选择消耗，并标记失败/未匹配；不把未花完预算当成完整对照。
- 完成的实验单元可恢复复用；未完成子策略的优化器恢复尚未实现。目录中已有部分训练文件时会明确失败，不能冒称从中断步无缝续训。可用新的输出目录重跑该单元，调试开销另行记录。
- 测试失败和不可行结果保留；没有可行前沿时HV为0，IGD无定义时为null。共同IGD参考仅来自验证集。
- 清单锁定配置、DT模型哈希、种子、偏好和预算；不接受不同协议复用同一目录。

## 运行

短验证复现：

```bash
python -m vpp_research.fair_budget --config configs/fair_budget_smoke.json --output runs/fair_smoke --total-episodes 12 --seeds 31
```

更长预算、多种子的统一入口已可调用，下面命令本轮尚未执行：

```bash
python -m vpp_research.fair_budget --config configs/research_smoke.json --dt-model PATH_TO_DT/residual.json --output runs/fair_long --total-episodes 1200 --seeds 1 2 3 4 5
```

此命令按时域8步为每方法每种子分配9600步训练加选择交互，另有48步独立测试。1200是开发总回合预算，不是每个OLS子策略的训练回合。多种子完成后仍需学习曲线、置信区间及预算敏感性，增加回合数不自动证明收敛。

未完成项仍包括：长预算实际运行与统计、DT控制收益和漂移覆盖、完整真实EV数据实验、DR动态参数、IEEE69及目标设备计时/能耗实测。本轮没有新增这些方向的完成或性能主张。
