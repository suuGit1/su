# 外生奖励基准：候选方案及适用边界

这是一项独立、默认关闭的训练信号修复。成本、碳排放、备用的物理定义与评估值不变；不逐目标除以不同标准差，不重新解释偏好权重。

固定时域H、固定训练偏好w，以及外生曲线z不受控制策略影响时，定义b(z_t)为不调用可控资源时的外生参考向量。学习奖励取 r'_t=r_t-b(z_t)，则

\[
J'_w(\pi)=J_w(\pi)-\mathbb{E}_{z}\left[\sum_{t=0}^{H-1}\gamma^t w^\top b(z_t)\right].
\]

右侧第二项与策略无关，因此在这些条件下最优策略不变。这是目标恒等式，不是有限样本PPO改进保证。若采用受动作影响的提前终止、内生电价或依据策略状态自适应修改的偏好，就不能直接沿用此结论。

参考净负荷为负荷减原始PV/风电；经济参考仅核算固定购售电价下的该净负荷，碳参考只核算其进口排放，备用参考为零。参考不使用ESS动作/SOC、EV剩余需求、安全修正或C3决策。真实外生量仅用于事后训练奖励，与既有物理奖励一样，不加入actor/critic观察或线上推理。

原始objective_vector继续用于轨迹、指标、选模与报告；learning_objective_vector只用于训练更新。exogenous_reference_vector逐步保存，能验证原向量=学习向量+参考向量。官方普通/固定MAPPO及集中PPO也通过同一环境开关获得一致的奖励处理。MILP/MPC物理优化目标不改：给定预测与偏好，该外生参考是决策无关常数。

既有八回合轨迹的离线诊断：碳奖励标准差1.7413降至0.2235；零critic下碳GAE标准差17.8539降至0.4448。它说明外生背景可以掩盖可控信号，但不证明某条策略已因此改善。候选验证用新的独立代码副本、相同种子和训练量，结果另列。
